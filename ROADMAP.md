# CONTRACT roadmap

- [x] Initial transport-independent application core.
- [x] Static routes and named path parameters.
- [x] Distinguish 404 and 405.
- [ ] Route conflict detection and deterministic precedence.
- [ ] Middleware lifecycle with short-circuit semantics.
- [ ] Query and header abstractions.
- [ ] Request/body/header limits and validation interfaces.
- [ ] HTTP/1.1 adapter with parser conformance tests.
- [ ] Structured errors, tracing and metrics hooks.
- [ ] Fuzzing, benchmarks, security review and compatibility policy.

The project is experimental and not production-ready.
